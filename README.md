# Winx Dress Up ✨

Красивая одевалка персонажей Клуба Винкс на Jetpack Compose.

## Возможности
- 8 фей: Блум, Стелла, Флора, Муза, Текна, Лейла, Рокси, Дафна
- Классическая одевалка: причёски, верх, низ, обувь, крылья, аксессуары, макияж
- Несколько волшебных комнат (Алфея, сад, спальня, Облачная Башня, океан, сцена)
- Сохранение нарядов + галерея
- Современный Material 3 UI в сказочном стиле

## Сборка
```bash
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/`

## Подпись
Приложение подписано выделенным keystore. Для обновлений используй тот же keystore и увеличивай versionCode.
